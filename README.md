# Globe VPN — клиент в дизайне `vpn.html`, с настоящим туннелем

Android-клиент, собранный из присланного прототипа: тот же визуальный язык (бумага/ночь,
точечный глобус, моно-подписи, док на чистом блюре), но внутри — **рабочий VPN на ядре
Xray-core**: `VpnService` поднимает `tun`, ядро шифрует и гонит весь трафик через выбранный
сервер.

## Как работает подключение

1. Пользователь выбирает сервер — в списке, по **тапу на точку-флаг на глобусе** или из
   подписки, — и **тянет ползунок вправо**. Пока тянете, иконка питания превращается в
   стрелку, а подпись едет вслед за ползунком к центру; дошли до 62 % — подключение, не
   дошли — ползунок возвращается. После подключения ползунок сжимается в круг со «стопом»,
   тап по нему отключает.
2. Интерфейс собирает из ссылки (`vless://`, `vmess://`, `trojan://`, `ss://`) полный
   JSON-конфиг Xray: `inbounds[tun]` + `outbounds[proxy, direct, blackhole]` +
   `routing` + `dns` + `stats` (TLS, Reality, WS, gRPC, XHTTP, HTTP/2, KCP, QUIC,
   TCP-с-маскировкой, flow `xtls-rprx-vision`).
3. `MainActivity` запрашивает системное разрешение VPN (`VpnService.prepare`).
4. `GlobeVpnService` вызывает `establish()` → получает fd туннеля → отдаёт его ядру
   (`CoreController.startLoop(config, fd)`); адреса `10.10.14.1/30` и `fc00::10:10:14:1/126`,
   маршруты `0.0.0.0/0` и `::/0`, DNS 1.1.1.1 / 8.8.8.8 / 1.0.0.1, своё приложение исключено.
5. Статистика (`queryAllOutboundTrafficStats`) раз в секунду уходит в интерфейс:
   `ЗАЩИЩЕНО · 42 мс`, ↓/↑ трафик и время сессии. Ошибки ядра показываются текстом состояния.

Foreground-сервис с типом `specialUse`, уведомление с кнопкой возврата в приложение,
`SUPPORTS_ALWAYS_ON` + сохранение последнего конфига, поэтому туннель поднимается и при
перезапуске системы / always-on VPN.

## Добавление: один экран, автоопределение

В шапке библиотеки — только **«+»** и **QR**. Оба ведут туда же: вставьте что угодно, тип
определится сам.

* `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `tuic://` → **сервер**:
  чип «Сервер · VLESS», превью города и адреса, кнопка «Добавить сервер».
* `http(s)://…` → **подписка**: чип «Подписка · ссылка», кнопка «Добавить подписку»
  (имя подставится из домена, если не указать).
* base64/список ссылок без домена → **подписка из содержимого**.
* QR — камера в приложении (`getUserMedia` + jsQR), распознанный код уходит в тот же экран
  и определяется тем же правилом. Если камеру не разрешили, экран предлагает ввести вручную.

## Главный экран

* Глобус из точек: города-серверы — точки с флагом, «вы» — перекрестие в вашем городе,
  между ними дуга маршрута в цвете акцента; точки планеты рядом с дугой слегка подсвечиваются
  акцентом, по дуге бежит «пакет».
* **Город определяется сам**: сначала по часовому поясу (мгновенно, офлайн), затем уточняется
  по IP (`Native.locate`) и привязывается к ближайшему городу из справочника на 228 городов и
  51 страну. Результат кешируется на 6 часов; подпись под линией маршрута и начало дуги
  обновляются.
* Во время вращения карты подписи городов скрываются — «крутящаяся табличка» не висит.

## Библиотека

* Карточки-группы: подписка и «Вручную». В заголовке — только название, счётчик и шеврон;
  раскрытие/закрытие анимировано высотой, состояние запоминается.
* Строка сервера: флаг, город, `страна · источник`, задержка и протокол справа.
* **Зажатие строки** (~0,5 с) открывает настройки этого клиента: название, адрес, порт,
  SNI, `allowInsecure`, Mux, «Проверить пинг», «Сохранить». Правки уходят прямо в конфиг Xray.
* Задержка у каждого сервера и цвет по качеству: `< 80 мс` акцент, `80–200 мс` янтарь,
  `> 200 мс` красный, без ответа — «нет ответа».
* Поиск по городу/стране/протоколу/подписке; сортировки: имя, пинг, страна, новые.

## Статистика

Отдельная вкладка в доке.

* Большое число — часы в защищённом режиме за текущий месяц, рядом «сегодня / за 7 дней /
  дней подряд».
* **Календарь как на GitHub**: 20 недель по дням, чем больше часов в VPN за день — тем ярче
  квадрат (5 уровней в цвете акцента), у каждой клетки подсказка с датой и временем.
* Трафик принято/отдано за всё время и число сессий.
* «Последние дни» — полоски времени за неделю.
* Данные пишутся в `localStorage` (`vpn.usage`): секунды, трафик и сессии по дням; кнопка в
  шапке очищает статистику с возможностью вернуть.

## Что ещё умеет

* **Подписки по URL** — загрузка нативным HTTP-клиентом (без CORS), base64 и plain-списки,
  офлайн-фолбэк на сохранённое содержимое, обновление по ⟳.
* **Настройки пинга**: авто-проверка, «только выбранный», интервал 1/5/15 мин, таймаут
  1,2/2,5/4 с (уходит в нативный сокет), кнопка «Измерить сейчас».
* Вставка из буфера, экспорт/импорт бэкапа, deep links (`vless://` и др. из других приложений),
  нативная кнопка «Назад», тактильный отклик, кастомные системные панели.
* **Кастомизация**: тема Бумага/Ночь, 10 акцентов + свой цвет, мягкие формы, компактные
  списки, уменьшение движения, размер/подписи/скорость флагов на карте, автоподключение.
  Всё в `localStorage`.
* Док — нижняя панель на чистом блюре (`backdrop-filter` в один слой) с плашкой активного
  раздела.

## Ограничения (честно)

* Поддерживаются протоколы ядра Xray: VLESS, VMess, Trojan, Shadowsocks (+ их транспорты).
  **Hysteria2 и TUIC** ядром Xray не поддерживаются — при выборе такого сервера приложение
  честно скажет об этом, а не сделает вид, что подключилось.
* В APK только arm-библиотеки ядра (arm64-v8a, armeabi-v7a). На x86-эмуляторах не запустится,
  на реальных телефонах — да.
* `geoip.dat`/`geosite.dat` не упакованы: правила используют только IP-подсети, сплит-туннеля
  по гео-базам нет.
* Определение города по IP требует сети; без неё остаётся точность до часового пояса.
* QR-сканер требует разрешения камеры (запрашивается при открытии экрана сканирования).
* Проверка на живом устройстве не выполнялась (в песочнице нет Android): конфиги ядра
  провалидированы по схеме Xray и протестированы на уровне интерфейса, но первый реальный
  запуск стоит делать с известным рабочим сервером.

## Пересборка

```bash
bash tools/setup_env.sh         # один раз: SDK, JDK 17, Playwright (всё вне воркспейса)
python3 tools/build_html.py     # интерфейс: source/vpn.html → app/assets/vpn.html
tools/build-apk.sh              # APK → release/GlobeVPN-1.0.0.apk (+ копия в корне)
python3 tools/qa_shots.py       # скриншоты → release/screenshots/
```

Проверки: `qa_quick.py` (экраны и ошибки консоли), `qa_add.py` (автоопределение
сервер/подписка, QR-экран), `qa_slider.py` (драг ползунка и «стоп»), `qa_globe.py` (тап по
точке = подключение, скрытие подписи при вращении), `qa_locate.py` (город по IP и кеш),
`qa_stats.py` (трекинг времени и календарь), `qa_flow.py` (полный сценарий: серверы →
сортировки → зажатие строки → конфиг ядра).

Подпись — `keystore/globevpn.jks`, пароль `globevpn24`, alias `globevpn`
(`CN=Globe VPN`, отпечаток SHA-256 `25e45c02…94e86ce`).
